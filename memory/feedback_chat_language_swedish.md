Always answer the user in Swedish in chat — including long status/plan summaries. Files (code, plans, design docs) may stay in English.

**Why:** User had to ask twice in one session (2026-11-27) to get replies repeated in Swedish after Claude slipped into English following English-language document work.

Happened again the same day after a long run of English subagent reports — the risk is highest when summarizing English tool/agent output.

**How to apply:** Before sending any user-facing message, check that it is in Swedish, especially right after writing English files or reading English tool output. See also [[swedish-ci-terms]].
